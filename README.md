# 同路 · 校园跑腿互助 Demo

手机优先的校园互助交互演示，黑白及中性色为主。虚构校园为南城大学，所有身份、任务、认证、消息和金额均为模拟。

**固定在线地址：https://zhuyifan001225.github.io/campus-running-demo/**

## 本地运行

需要 Node.js 20.11 或更新版本，无需安装依赖：

```sh
npm run dev
```

打开 `http://127.0.0.1:4173/campus-running-demo/`。ES 模块需要通过 HTTP 访问，不能直接双击 HTML 文件运行。

## 体验建议

1. 默认以未认证的新同学进入，可以看脱敏任务，接单时触发模拟认证。
2. 页面顶部 `DEMO` 可切换林予安、周以宁两位已认证演示学生。
3. 周同学接下林同学的午餐任务，开始履约，提交商品报价 26 元。
4. 在任务内切换为林同学，确认商品、报价与预算；再切回周同学记录模拟购买和凭证，提交送达。
5. 林同学确认收货：预付 35 元，结算 31 元，退回 4 元，双方可各评价一次。

新任务、取消协商、地点变更、争议提交、任务内模拟消息、举报与信用明细均可体验。首次不必填写真实材料或手机号。演示任务会按实际时间到期，需要重新体验时，可在 DEMO 面板确认重置。

## 检查

```sh
npm run check
npm test
```

核心规则测试覆盖认证、同校权限、自接/重接、预算授权、退款守恒、取消协商、争议暂停、地点变更、评价及任务修改。

## 文件与后续开发

- `产品规则与交互说明.md`：用户已确认的规则、信任与隐私设计、异常流程。
- `CLAUDE_HANDOFF.md`：开发交接、实际实现范围与明确未实现的能力。
- `lib/model.js`：数据、权限、任务/采购状态与费用计算。
- `app.js`：页面、弹层、路由、本地存储、表单与事件。
- `styles.css`：手机与电脑响应式样式；`lib/icons.js` 和 `assets/`：本地 SVG。
- `scripts/mobile-preview.html`：用于同时检查 390 px / 320 px 布局的辅助页面。

## 部署

GitHub Pages 从 `main` 分支根目录发布，推送后自动部署。保持仓库名、域名与 `/campus-running-demo/` 路径不变。当前不需要构建工具，不依赖远程字体或图片。

**这不是可真实交易的平台。** localStorage 不跨设备同步，也无法保证真实身份、数据保密或多人并发。正式产品需要后端身份核验、授权、数据库、支付服务及独立运营审核。不要在公开仓库中放任何真实证件、取件码、联系方式或密钥。
