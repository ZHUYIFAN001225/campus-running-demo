# 同路 · 校园跑腿互助 Demo

手机优先的校园互助交互演示，黑白及中性色为主。虚构校园为南城大学，所有身份、任务、认证、消息和金额均为模拟。

**固定在线地址：https://zhuyifan001225.github.io/campus-running-demo/**

## 本地运行

已在当前环境的 Node.js 24 验证，无需安装依赖：

```sh
npm run dev
```

打开 `http://127.0.0.1:4173/campus-running-demo/`。ES 模块需要通过 HTTP 访问，不能直接双击 HTML 文件运行。

## 两条清楚的使用流程

- **找人帮忙**：发布取送需求，选择当面交接或事先授权的指定交接架自取。进行中的任务优先显示，点开看位置、取件/送达阶段和凭证。
- **顺路接单**：先选出发地、目的地和最多愿意绕多少米，地图聚合沿途取件点，接单前看到取送点、到取件点距离、额外绕行与报酬。不能接自己的任务。
- **地图自定义落点**：发布时的取送点、接单时的出发地和目的地均可点地图命名；支持一个可选途经点。顺路推荐按绕行偏好筛选，全校需求让冷门位置也能被发现。
- **持续看位置**：接单确认后自动进入订单地图，人物按约 1.2 米/秒模拟移动；取件后才开始送往交接点。关闭或刷新后延续任务时间，不再播放24秒短片。
- **钱包收款**：底部钱包显示待结算报酬、累计已到账、跑腿收入、垫付返还、预付中及退款记录。确认完成后才入账，仅模拟记账，不接入真实支付或提现。

## 体验建议

1. 默认以未认证的新同学进入，可看公开的公共取送点与路线，取件凭据、对话和配送位置不向旁观者开放。
2. 页面顶部 `DEMO` 可切换林予安、周以宁两位已认证演示学生。
3. 完成学生认证后，还需开通演示接单身份。可接林同学的北门包裹任务，确认取件后看地图推进，记录放置凭证并通知对方。接单者无需等发布者取件，可继续接下一项运输。
4. 自取任务必须发布者事先授权地点；超出自取提示时间不会自动免责或结算。实际取到后由发布者确认。
5. 也可体验代买：周同学接林同学的午餐任务，接单即出发，提交商品报价 26 元。
6. 在任务内切换为林同学，确认商品、报价与预算；再切回周同学记录模拟购买和凭证，提交送达。
7. 林同学确认收货：预付 35 元，结算 31 元，退回 4 元，双方可各评价一次。

新任务、取消协商、地点变更、争议提交、任务内模拟消息、举报与信用明细均可体验。首次不必填写真实材料或手机号。演示任务会按实际时间到期，需要重新体验时，可在 DEMO 面板确认重置。

## 检查

```sh
npm run check
npm test
```

核心规则测试覆盖认证、同校权限、自接/重接、预算授权、退款守恒、取消协商、争议暂停、地点变更、评价及任务修改。

## 文件与后续开发

- `产品规则与交互说明.md`：用户已确认的规则、信任与隐私设计、异常流程。
- `CLAUDE_HANDOFF.md`：开发交接、实际实现范围与明确未实现的能力。
- `lib/model.js`：数据、权限、任务/采购状态与费用计算。
- `lib/campus.js`：虚构校园路网、最短路径、绕行计算和数据驱动的示意地图。
- `lib/experience.js`、`experience.css`：第二版双入口首页、沿途列表与配送位置演示。
- `app.js`：页面、弹层、路由、本地存储、表单与事件。
- `styles.css`：手机与电脑响应式样式；`lib/icons.js` 和 `assets/`：本地 SVG。
- `scripts/mobile-preview.html`：用于同时检查 390 px / 320 px 布局的辅助页面。

## 部署

GitHub Pages 从 `main` 分支根目录发布，推送后自动部署。保持仓库名、域名与 `/campus-running-demo/` 路径不变。当前不需要构建工具，不依赖远程字体或图片。

**这不是可真实交易的平台。** 地图基于虚构路网，位置和预计时间为模拟，不是 GPS 或真实导航；照片为 AI 生成样例，不证明真实交接或存在监控。localStorage 不跨设备同步，也无法保证真实身份、数据保密或多人并发。正式产品需要后端身份核验、授权、数据库、支付服务及独立运营审核。不要在公开仓库中放任何真实证件、取件码、联系方式或密钥。
