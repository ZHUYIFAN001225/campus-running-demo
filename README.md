## 当前能力

- 同账号“找人帮忙 / 顺路接单”，同校有效认证+独立接单资格，具体任务绑定双方。
- 打开先看附近和校门单量，目的地/途经点可选；全校和急单筛选，接单前看到取送点、距离、期限、费用及绕行。
- 62笔密集示例覆盖9个固定点，每12秒模拟新增1–2单，可暂停/补充；计数来自真实本地待接任务。
- 地图缩小聚合、放大展开，平滑缩放/拖动/受限惯性；“设置我的位置”下全图点红标也直接落点，完成后恢复看需求。
- 地图+短表单发布，自定义公共取送点；加急加价、预约、代买和交接方式按需展开。
- 最多4单共享配送者轨迹，逐站取送与单独确认/结算，追加单从当前位置规划。
- 按约1.2米/秒持续模拟移动，显示本单剩余距离/预计送达时刻，刷新延续；不会靠时间自动取件或完成。
- 公共点当面交接，或事先明确授权指定架自取；凭证和通知后可离开，不倒计时免责。
- 消息含订单私聊/进度提醒，文字/图片预览发送、大图、本地保存；同源多标签静默更新并保留输入。
- 钱包区分待结算、净收入、垫付返还、预付和退款；采购报价/替换/超额双方授权，收货后一次结算与评价。
